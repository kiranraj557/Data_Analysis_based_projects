# 🍕 Pizza Sales SQL Analysis

## 📌 Overview
This project analyzes a pizza sales database using SQL to uncover business insights such as sales performance, customer ordering patterns, and revenue trends. It demonstrates the use of SQL concepts like **JOINs, Aggregate Functions, Subqueries, GROUP BY, and Window Functions**.

## 📂 Database Tables
- **orders** – Customer order details
- **order_details** – Quantity of pizzas ordered
- **pizzas** – Pizza sizes and prices
- **pizza_types** – Pizza names and categories

## 📊 Questions Solved
1. Total number of orders placed.
2. Total revenue generated.
3. Highest-priced pizza.
4. Most common pizza size ordered.
5. Top 5 most ordered pizza types.
6. Total quantity ordered by pizza category.
7. Distribution of orders by hour.
8. Category-wise pizza distribution.
9. Average pizzas ordered per day.
10. Top 3 pizza types by revenue.
11. Percentage revenue contribution by category.
12. Cumulative revenue over time.
13. Top 3 revenue-generating pizzas in each category.

## 🛠 SQL Concepts Used
- SELECT
- JOIN
- GROUP BY
- ORDER BY
- Aggregate Functions (`COUNT`, `SUM`, `AVG`)
- Subqueries
- Window Functions (`RANK`, `SUM OVER`)
- LIMIT
